# Production hardening reporting rules

Report these states separately:

```text
v0.1 deterministic publishing core: 10/10 — 100% complete
v0.1.8 production release: pending / accepted
v0.1 Production Hardening: X/9 gates complete
Full Book System OS: incomplete and not baselined
```

Do not average these values into one repository percentage.

Activity, commit count, open pull requests and documentation volume are not completion evidence.
