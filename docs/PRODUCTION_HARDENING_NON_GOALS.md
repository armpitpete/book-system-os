# Production hardening non-goals

The v0.1 Production Hardening milestone exists to make the completed deterministic core recoverable, observable, bounded and safer to operate.

It does not authorise:

- `POST /api/v1/validate`;
- any `/api/v1/publish*` route;
- print imposition, cover, spine, bleed or colour-production workflows;
- physical proof or publication approval systems;
- Semantic Architect behaviour;
- editorial rewriting, summarisation or content generation;
- multi-user accounts, billing or public SaaS operation;
- distributed workers;
- database-backed orchestration;
- unrelated visual redesign.

Discoveries in these areas must be recorded separately and must not be implemented inside a hardening lane.
