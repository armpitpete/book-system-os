# Production hardening owner boundaries

Owner authority is required for:

- merging a pull request;
- production deployment;
- destructive or irreversible data changes;
- expanding a gate beyond issue #31;
- beginning v0.2 implementation;
- entering print-production or Semantic Architect scope.

Owner authority is not required for ordinary reversible implementation inside an authorised lane, including tests, repairs, commits, pushes and draft pull-request updates.
